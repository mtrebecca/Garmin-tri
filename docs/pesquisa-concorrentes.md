# Pesquisa de concorrentes (out/2026)

| Concorrente | O que faz | Preço | Limitação principal |
|---|---|---|---|
| Alertas nativos Garmin | "Comer/beber" por tempo ou distância | Grátis | Não diz o quê nem quanto; não registra; some em segundos |
| Garmin Connect+ nutrição | Diário alimentar geral | Assinatura | Não é para durante o treino; app do relógio instável |
| EatMyRide | Plano por rota/intensidade + widgets Connect IQ | £5,99/mês | Sync lento; setup trabalhoso; registro não funciona sem touch |
| Saturday | Plano de carbo/hidratação | US$ 2,99–5,99/mês | Unidades (só ml) |
| Enduraid | Plano por perfil/clima/terreno | Assinatura | — |
| Precision Fuel & Hydration | Planejador web detalhado | Grátis | Sem Garmin; complexo |
| Data fields Connect IQ (Eat! Drink! Reminder!, FuelTheGoal) | Timers | Grátis | Até 5 alarmes, sem pop-up, sem registro |
| FuelSteps (Connect IQ, 2026) | Data field com plano de gel/carbo por distância ou tempo, alerta em tela cheia | Grátis | Foco em carboidrato; sem hidratação/sódio nem planejado × realizado no celular (a confirmar) |

## Dores → diferenciais do FuelUp

| Dor | Diferencial |
|---|---|
| Alerta some e passa despercebido | Alerta persistente, vibra até confirmar/pular/adiar |
| Alerta genérico, sem registro | Mostra produto e gramas; registra planejado vs. realizado |
| Alertas nativos falham em treino estruturado | Cronograma próprio por tempo de timer |
| Relógios sem touch ficam de fora | Interface só com botões |
| Tudo é assinatura | Grátis |
| Faltam produtos locais | Biblioteca inicial com produtos vendidos no Brasil |
| Planejadores complexos demais | Modo simples + modo avançado |
| Limite de segmentos em provas longas | Sem limite prático de itens |
